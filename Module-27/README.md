# Module 27: Azure Backup and Site Recovery

**Course day:** 27 | **Exam domain:** Monitor and maintain

## Learning path
Distinguish Azure Backup (data protection and restore) from Azure Site Recovery (replication and workload failover). Learn Recovery Services vaults, Backup vaults, policies, retention, restore points, recovery plans, failover, and failback.

## Lab and practice
Use a workflow diagram or inspect an existing vault. Protecting a VM creates storage and retention charges. Only run a live backup/restore with authorization, a disposable workload, a reviewed policy, and a cleanup plan.
