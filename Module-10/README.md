# Module 10: Azure Files

**Course day:** 10 | **Exam domain:** Storage

## Learning path
Learn Azure file shares, SMB and NFS, identity-based authentication, access keys, snapshots, soft delete, quotas, and mounting concepts. Know protocol and authentication limitations for each configuration.

## Lab and practice
Use a diagram or read-only walkthrough if no low-cost share is available. If you create a share, use minimal capacity, avoid a paid VM mount unless approved, and remove the share and account after checking charges.
