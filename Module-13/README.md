# Module 13: Managed Disks and Encryption

**Course day:** 13 | **Exam domain:** Compute

## Learning path
Compare Standard HDD, Standard SSD, Premium SSD, Premium SSD v2, and Ultra Disk where supported. Learn disk sizing/performance, snapshots, encryption at host, attaching disks, and the distinction between Azure disk configuration and guest OS partitioning/filesystems.

## Lab and practice
Use a diagram or inspect a VM's disk blade first. A disposable disk and snapshot may be billed. If provisioned, detach safely, remove snapshots and disks, and verify the VM is not retaining resources.
