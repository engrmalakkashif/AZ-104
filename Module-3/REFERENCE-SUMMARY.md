## Key Learnings

✅ **RBAC Model:** Security Principal + Role Definition + Scope  
✅ **Role Assignment:** Assign roles to users/groups at specific scopes  
✅ **Scope Hierarchy:** Understand inheritance from Management Group → Subscription → RG → Resource  
✅ **Custom Roles:** Create tailored roles with specific permissions  
✅ **Effective Permissions:** Verify what users can actually do  

## Key Takeaways

1. **Principle of Least Privilege:** Assign minimum permissions needed
2. **Use Groups:** Easier to manage than individual assignments
3. **Scope Matters:** More specific scope = better security
4. **Review Regularly:** Audit access assignments periodically
5. **Custom Roles:** Create only when needed, built-in roles are usually sufficient
