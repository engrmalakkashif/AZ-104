# Module 20: Network Security Groups and Application Security Groups

**Course day:** 20 | **Exam domain:** Networking

## Learning path
Understand inbound/outbound NSG rules, source/destination, protocols, ports, priorities, default rules, subnet/NIC association, effective security rules, and ASGs. Lower numerical priority values are evaluated first.

## Lab and practice
Model a least-privilege SSH/HTTP rule and predict the result before applying it. In a live lab, restrict SSH/RDP to your current IP, verify effective rules, then remove the temporary rule.
