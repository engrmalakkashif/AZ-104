# Module 3: Azure Subscriptions & Governance

**Day:** 3 | **Duration:** 5 hours | **Skill Domain:** Manage Azure subscriptions and governance (20-25%)

## 📚 Module Overview

This module covers governance in Azure including policies, resource locks, tags, and cost management. You'll learn how to enforce compliance, protect resources, and implement organizational standards.
