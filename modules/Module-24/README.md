# Module 24: Azure Monitor and Metrics

**Course day:** 24 | **Exam domain:** Monitor and maintain

## Learning path
Learn Azure Monitor, platform metrics, logs, Activity Log, diagnostic settings, Log Analytics workspaces, retention, and basic KQL. Metrics and logs have different data models, retention, and costs.

## Lab and practice
Inspect platform metrics and Activity Log on an existing resource. Enable diagnostic ingestion only after checking destination, retention, and pricing; remove test settings and data when appropriate.
