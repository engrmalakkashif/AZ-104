# Module 28: Integrated Azure Architecture Lab

**Course day:** 28 | **Focus:** Integrate all AZ-104 domains

## Architecture exercise
Design a small environment containing Entra ID, least-privilege RBAC, policy, tags/locks, a VNet with subnets and NSGs, compute, private access to storage, monitoring/alerts, and backup. Label trust boundaries, DNS flow, route flow, and recovery objectives.

## Lab and practice
Complete the architecture on paper first. Provision only components that fit an approved budget; multi-resource environments can generate costs even when idle. If you deploy, use one tagged resource group, restrict inbound access, record every resource, and verify complete cleanup.
