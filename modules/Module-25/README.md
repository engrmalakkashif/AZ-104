# Module 25: Alerts, Action Groups, and Insights

**Course day:** 25 | **Exam domain:** Monitor and maintain

## Learning path
Compare metric, log, and Activity Log alerts. Learn alert rules, action groups, alert processing rules, and VM/Storage/Network insights. Understand signal, condition, evaluation frequency, severity, and notification/action.

## Lab and practice
Design a CPU threshold alert and trace its action group. Configure a real alert only in an authorized test scope; email/SMS delivery and Log Analytics ingestion have service-specific limits and possible charges.
