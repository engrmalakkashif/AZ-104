# Module 11: Storage Operations and Lifecycle

**Course day:** 11 | **Exam domain:** Storage

## Learning path
Practice Azure Storage Explorer and AzCopy, lifecycle rules, object replication, encryption, and network restrictions. Review storage account and Blob topics from Days 7–10.

## Lab and practice
Transfer a tiny test object using an authorized identity or a narrowly scoped SAS. Create or inspect a lifecycle rule without applying an unexpectedly broad deletion action. Complete 30–40 storage questions and clean up test data.
