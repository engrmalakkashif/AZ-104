# Module 15: ARM Templates

**Course day:** 15 | **Exam domain:** Compute and resource deployment

## Learning path
Read ARM JSON structure: schema, parameters, variables, resources, outputs, dependencies, and deployment modes. Understand declarative deployment and how Azure Resource Manager evaluates a template.

## Lab and practice
Validate a minimal template and use deployment validation/what-if before applying it. Inspect the proposed changes. Only deploy into a disposable resource group, then remove all created resources.
