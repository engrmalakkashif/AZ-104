# Module 3: Azure Role-Based Access Control

**Course day:** 3 | **Exam domain:** Identity and governance

## Learning path
Understand security principals, role definitions, role assignments, scope inheritance, built-in roles (Owner, Contributor, Reader, User Access Administrator), and custom roles. Distinguish Azure RBAC from Microsoft Entra directory roles.

## Lab and practice
At a disposable resource group, inspect role assignments and practice least-privilege scope selection. If you have authorization, assign Reader to a test identity and remove the assignment afterward. Never alter production access.
