# Module 23: Azure DNS and Load Balancing

**Course day:** 23 | **Exam domain:** Networking

## Learning path
Study public/private DNS zones and records, Azure Load Balancer frontend IPs, backend pools, health probes, rules, and public versus internal load balancing. Understand that health probes determine whether backends receive traffic.

## Lab and practice
Build a DNS and load-balancer diagram. A live multi-VM configuration can be chargeable; avoid it unless budgeted. If deployed, restrict inbound access and delete the load balancer, public IPs, VMs, and disks.
