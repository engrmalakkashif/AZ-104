# Module 2: Entra Users, Groups, Licenses, and SSPR

**Course day:** 2 | **Exam domain:** Identity and governance

## Learning path
Study user and group properties, assigned and dynamic membership, direct and group-based licensing, usage location, self-service password reset (SSPR), and authentication methods. Licensing may require paid entitlements; understand the workflow without purchasing anything.

## Lab and practice
Build a fictional team structure on paper or with test objects in an authorized tenant. Inspect SSPR settings and identify which licenses and roles would be required. Never assign a paid license solely for practice.
