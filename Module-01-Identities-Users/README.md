# Module 1: Microsoft Entra Users & Groups

**Day:** 1 | **Duration:** 5 hours | **Skill Domain:** Manage Azure identities and governance (20-25%)

## 📚 Module Overview

This module covers the fundamentals of managing users and groups in Microsoft Entra ID (formerly Azure AD). You'll learn to create cloud users, manage group properties, assign licenses, and configure self-service password reset.

## 🎯 Learning Objectives

By the end of this module, you will:
- ✅ Create cloud users in Microsoft Entra ID
- ✅ Manage user and group properties
- ✅ Manage licenses in Microsoft Entra ID
