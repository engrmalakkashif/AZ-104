# Module 08: Azure SQL Database

**Course status:** Supplemental; this service is not assigned a core day in the supplied 30-day AZ-104 sequence.

Prioritize the [30-day study plan](../../docs/30-DAY-STUDY-PLAN.md) and the five AZ-104 skill domains first. This folder is retained for optional Azure administration context; use the current Microsoft Learn material for Azure SQL Database because its compute models, backup behavior, and pricing options change over time.

Before creating a database for practice, check the selected compute model, region, backup retention, and current price. Delete the database and any associated logical server or monitoring resources after the exercise.
