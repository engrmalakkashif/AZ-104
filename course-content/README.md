# Course Content Reference

The canonical course order is the root-level `Module-1` through `Module-30` folders. This directory preserves the existing detailed topic-based material, labs, scripts, and quick references as supporting course content; its legacy module numbers are not the 30-day schedule.

Use the corresponding day module for the current learning objective, and consult these references where linked. Supplemental subjects outside the 30-day plan are retained here for optional study. Nothing in this directory should be read as a separate competing schedule.
