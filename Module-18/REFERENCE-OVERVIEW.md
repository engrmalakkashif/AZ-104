# Module 09: Azure App Service

**Course day:** 18

**Exam domain:** Deploy and manage Azure compute resources

Start with the [complete App Service lesson](content/README.md). It follows the 15-part instructor format and includes Portal settings, Azure CLI examples, a low-cost lab with cleanup, troubleshooting, exam points, and interview/practice questions.

> App Service plans, deployment slots, backups, custom domains, TLS, and networking features have tier-dependent availability and may incur charges. Check current regional pricing and feature support before creating resources. A Cost Management budget is an alert, not a spending cap.

The lesson's lab can be completed as a read-only Portal walkthrough; provisioning is optional. Delete the disposable resource group after any live exercise.
