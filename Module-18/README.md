# Module 18: Azure App Service

**Course day:** 18 | **Exam domain:** Compute

## Learning path
Learn App Service plans, web apps, runtime configuration, scaling, deployment slots and swaps, custom domains, TLS, backups, managed identity, and networking. Distinguish app-level settings from plan-level compute and inbound from outbound networking.

## Lab and practice
Start with the full lesson's read-only Portal walkthrough. Provisioning is optional; tiers, slots, backups, and networking may cost money. Delete the disposable plan and app after a live lab.
