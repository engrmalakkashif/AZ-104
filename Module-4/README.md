# Module 4: Azure Policy

**Course day:** 4 | **Exam domain:** Identity and governance

## Learning path
Learn policy definitions, assignments, parameters, initiatives, exemptions, compliance evaluation, and effects: Audit, Deny, Modify, Append, DeployIfNotExists, and Disabled. Understand that policy evaluates resource configuration; it is not a permissions grant.

## Lab and practice
Prefer a built-in Audit policy at a disposable resource-group scope. Observe compliance, then remove the assignment. If testing Deny, use a non-production scope and a harmless test deployment; remove the assignment afterward.
