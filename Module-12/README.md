# Module 12: Azure Virtual Machines

**Course day:** 12 | **Exam domain:** Compute

## Learning path
Study VM images, sizes, OS and data disks, NICs, public/private IPs, NSGs, extensions, and deployment choices. A VM is a compute resource plus associated networking and storage resources.

## Lab and practice
Prefer a template review or existing training VM. A live VM can incur compute, disk, and public IP charges. If approved, use the smallest eligible size, restrict SSH to your IP, stop/deallocate and then delete the VM and related resources.
