# Module 19: Virtual Networks and Subnets

**Course day:** 19 | **Exam domain:** Networking

## Learning path
Study VNet address spaces, CIDR, subnet planning, reserved addresses, NICs, private and public IPs, static/dynamic assignment, and regional scope. Practice identifying overlapping address ranges.

## Lab and practice
Design a VNet with Web, App, and DB subnets on paper first. A VNet-only design can be reviewed without compute; if deployed, use a disposable resource group and remove all networking resources afterward.
