# Module 1: Microsoft Entra ID Fundamentals

**Course day:** 1 | **Exam domain:** Identity and governance

## Learning path
Learn tenant and directory, users, groups, cloud-only versus hybrid identities, guest users, authentication versus authorization, and security versus Microsoft 365 groups. Define each term and explain where it fits in the tenant.

## Lab and practice
In an authorized test tenant, inspect directory settings and create a test cloud user and security group only if permitted. Do not invite a real external user or expose credentials. Review the objects and remove test objects if they are no longer needed.
