# Module 8: Azure Blob Storage

**Course day:** 8 | **Exam domain:** Storage

## Learning path
Understand storage accounts, containers, blobs, block/append/page blob types, access tiers (Hot, Cool, Cold, Archive), and upload/download operations. Archive data must be rehydrated before normal access.

## Lab and practice
Upload a small, non-sensitive file to a private container. Inspect its properties and tier, download it, then delete the blob and container. Check transaction and retrieval costs before testing tiers.
