# Module 22: Service Endpoints and Private Endpoints

**Course day:** 22 | **Exam domain:** Networking

## Learning path
Compare service endpoints with private endpoints. Understand private IP assignment, private DNS zones and records, storage firewall behavior, public network access, and the path from a VNet workload to PaaS.

## Lab and practice
Trace name resolution and network flow in a diagram. Live private endpoints, DNS zones, and supporting resources may incur charges. Use read-only inspection or a disposable storage account and remove every endpoint/DNS resource afterward.
