# Module 5: Resource Groups, Subscriptions, Locks, and Tags

**Course day:** 5 | **Exam domain:** Identity and governance

## Learning path
Explain the management-group, subscription, resource-group, and resource hierarchy. Learn resource locks (`CanNotDelete`, `ReadOnly`), tag inheritance considerations, and how governance scope affects resources.

## Lab and practice
Draw a hierarchy and apply tags to a disposable resource group. If testing a lock, use a temporary resource, verify its effect, remove the lock, and only then delete the resource. A lock is not a backup.
