# Module 21: VNet Peering and Routing

**Course day:** 21 | **Exam domain:** Networking

## Learning path
Learn regional/global VNet peering, peering state, address-space constraints, route tables, user-defined routes (UDRs), next-hop types, and system routes. Peering does not automatically imply transitive routing through a third VNet.

## Lab and practice
Draw two non-overlapping VNets and trace a packet route, including next hop and NSGs. Deploy peering only in an authorized disposable environment; remove peering and route tables after testing.
