# Start Here: AZ-104

This repository is organized around a **30-day Azure Administrator course**. You do not need to complete every optional Azure service; prioritize the current AZ-104 skills measured on Microsoft's exam page.

## Your first steps

1. Read the [30-day study plan](30-DAY-STUDY-PLAN.md), including its lab safety guidance.
2. Read the [quick start](QUICK-START.md) and verify your Azure CLI account context.
3. Start with Day 1 and follow the module links for the available supporting material.
4. Keep a lab log: objective, commands/settings, observed result, troubleshooting, and cleanup confirmation.

## Course sequence

| Days | Study area |
|---|---|
| 1–6 | Microsoft Entra ID, RBAC, policy, resource hierarchy, locks, tags, and cost |
| 7–11 | Storage accounts, Blob Storage, data protection, Azure Files, and storage operations |
| 12–18 | VMs, disks, availability, ARM, Bicep, containers, and App Service |
| 19–23 | VNets, NSGs, peering, routing, endpoints, DNS, and load balancing |
| 24–27 | Azure Monitor, alerts, Network Watcher, Backup, and Site Recovery |
| 28–30 | Integrated architecture, revision, and mock exam remediation |
