# Module 14: Availability and Scaling

**Course day:** 14 | **Exam domain:** Compute

## Learning path
Distinguish Availability Zones from Availability Sets, fault domains from update domains, and high availability from disaster recovery. Learn Virtual Machine Scale Sets (VMSS) and autoscale rules.

## Lab and practice
Compare architectures on paper first. A live multi-VM or VMSS lab can incur significant compute and networking costs; provisioning is optional. If used, set a small instance count and delete the scale set and supporting resources promptly.
