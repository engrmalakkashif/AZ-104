# Module 26: Azure Network Watcher

**Course day:** 26 | **Exam domain:** Monitor and maintain

## Learning path
Study Network Watcher, Connection troubleshoot, IP flow verify, NSG diagnostics, topology, and Connection Monitor. Diagnose source, route, NSG, destination, and DNS systematically.

## Lab and practice
Use a deliberately blocked flow in a diagram or disposable network and predict the tool result. If deploying test VMs, restrict access and check compute/monitoring charges; remove the network and VM resources after the exercise.
