# Module 17: Azure Containers

**Course day:** 17 | **Exam domain:** Compute

## Learning path
Understand Azure Container Registry (ACR), repositories, tags, authentication, Azure Container Instances (ACI), and Azure Container Apps (ACA), including container groups, ingress, revisions, environment variables, scaling, and restart behavior. AKS is not the focus of this core day.

## Lab and practice
Prefer a local build/run workflow. If pushing to ACR or deploying to Azure, check registry storage and running compute charges, use a disposable resource group, and remove the registry and app after testing.
