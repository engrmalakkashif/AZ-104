# Module 16: Azure Bicep

**Course day:** 16 | **Exam domain:** Compute and resource deployment

## Learning path
Learn Bicep declarations, parameters, variables, resources, modules, outputs, dependencies, `build`, `decompile`, and `what-if`. Relate Bicep syntax to the ARM deployment model.

## Lab and practice
Build and validate a small template locally. Run what-if against a disposable scope before deployment. Do not deploy VM/network resources unless the cost is approved; remove resources after any live test.
