# Module 7: Storage Accounts and Redundancy

**Course day:** 7 | **Exam domain:** Storage

## Learning path
Learn storage account types, performance tiers, endpoints, encryption, network access, and redundancy: LRS, ZRS, GRS, GZRS, RA-GRS, and RA-GZRS. Compare failure domains, replication scope, read access, and cost.

## Lab and practice
Inspect an existing account or create one only after checking regional pricing and redundancy availability. Record the selected account kind, performance, redundancy, network rules, and data protection settings; delete disposable storage after the lab.
